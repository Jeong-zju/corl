# PRISM 固定基座双臂实验一：日常衣物整理

## 实验定位

推荐英文名：`Daily Laundry Organization`

推荐数据集名：`zeno-ai/DailyLaundryOrganization`

该实验面向固定基座双臂机器人，模拟一个非常日常的抽屉衣物整理任务：抽屉左侧放待洗衣物，右侧放干净衣物。机器人从抽屉中取出一件衣物，先放到桌面中央的公共整理区。若衣物来自左侧待洗区，机器人用右手拿海绵刷在衣物表面象征性刷一下，再把衣物丢到脏衣篓；若衣物来自右侧干净区，机器人需要做一次简单对折或压平折叠，再把衣物推到干净衣物暂存区。

该任务的关键不是识别衣物本身，而是记住衣物最初来自抽屉哪一侧。衣物被拿到公共整理区后，当前画面中的衣物外观、位置和姿态尽量相似，正确后续动作必须依赖早期来源视觉和双臂执行前缀。

## PRISM 专属性

本实验专门服务于 PRISM 的记忆与路径条件能力。

- 早期视觉证据：衣物来自抽屉左侧待洗区还是右侧干净区。
- 长公共前缀：两类衣物都先被取出、放到同一个公共区域、压平到相似姿态。
- 分支动作差异：待洗衣物进入“刷一下 + 丢入脏衣篓”，干净衣物进入“简单折叠 + 推到干净区”。
- 当前观测不足：公共区域中的衣物外观尽量一致，普通 current-observation policy 很难只靠最后几帧决定后续动作。
- path/delta signature 作用明确：从左侧或右侧抽屉取物形成不同的早期运动路径，公共整理后需要被保留到分支阶段。

该实验比“看到脏污就刷、看到干净就折”更适合检验 PRISM。建议首轮使用颜色、材质和大小相近的毛巾、小 T 恤或方巾；待洗/干净身份由抽屉来源定义，不使用明显污渍、文字标签或颜色编码。

## 固定基座双臂平台设置

机器人固定在桌前，不移动底盘。建议保持当前代码仓库兼容的 17 维状态和动作格式：

- `observation.state`: `[0, 0, 0, left7, right7]`
- `action`: `[0, 0, 0, left7, right7]`
- 图像输入：顶部相机和左右腕部相机。

双臂角色建议：

- 左臂主要负责从抽屉取衣物、展开衣角或压住衣物边缘。
- 右臂主要负责拿海绵刷、辅助折叠和推送衣物。
- 部分 demonstrations 可交换左右臂职责，但首轮建议固定职责，降低控制难度。

所有操作都应采用宽容接触面：衣物尺寸建议 18-30 cm，海绵刷带 4-6 cm 粗柄，脏衣篓和干净暂存区都使用大开口容器或宽托盘。

## 场景布置

桌面前方放置一个浅抽屉或双区域收纳盒。抽屉左侧为待洗衣物区，右侧为干净衣物区。两个区域不要使用文字、颜色贴纸或电子提示，只通过自然空间位置定义。

推荐布置如下：

- 抽屉左侧：2-4 件待洗方巾或小衣物，外观与干净衣物尽量接近，可略微揉皱但不要有强视觉污渍。
- 抽屉右侧：2-4 件干净方巾或小衣物，叠放方式与左侧相似。
- 桌面中央：公共整理区，一块浅色软垫或布面工作区，尺寸约 35 x 45 cm。
- 桌面右前方：海绵刷放置槽，槽口宽，便于右手粗略抓取。
- 桌面左前方或侧边：脏衣篓，大开口，允许衣物被丢入即可。
- 桌面右后方：干净衣物暂存区，宽托盘或桌面标定区域，允许折叠后推入。

取走一件衣物后，抽屉中仍有其他相似衣物，因此当前视角不应出现明显“左侧空了”或“右侧空了”的答案。

## 任务流程

### Stage 1：从抽屉取出衣物

机器人从固定初始姿态开始，顶部相机能看到抽屉左右两侧和公共整理区。示教者每条 episode 指定从左侧待洗区或右侧干净区取出一件衣物。机器人夹住衣物的一角或宽边，将其拿出抽屉。

该阶段是记忆写入阶段。不要提供额外任务 id、文字指令、颜色标识或屏幕提示。

### Stage 2：放到公共整理区

机器人把衣物放到桌面中央公共整理区。无论来自左侧还是右侧，都尽量放到相同位置、相同朝向范围内。

建议加入统一整理动作：

- 左臂压住衣物一侧。
- 右臂轻推衣物边缘，让衣物大致摊平。
- 两类衣物都执行相同的 1-2 秒停顿或压平动作。

该阶段制造公共前缀，防止模型只靠最后动作尾巴判断分支。

### Stage 3：根据来源选择处理方式

机器人需要根据早期抽屉来源选择后续分支。

- 若衣物来自左侧待洗区：右臂去海绵刷槽取刷子。
- 若衣物来自右侧干净区：双臂进入简单折叠准备姿态。

此时公共整理区中的衣物本身不应提供可靠答案。

### Stage 4A：待洗衣物分支

右臂拿起海绵刷，在衣物表面做一次大面积象征性刷动。刷动不要求精确轨迹，只要求刷子接触衣物主体并移动 8-15 cm。左臂可以压住衣物，防止刷动时衣物被带走。

刷完后，机器人将衣物抓起或推入脏衣篓。成功标准为衣物主体进入脏衣篓，不要求姿态。

### Stage 4B：干净衣物分支

机器人执行一次简单折叠：例如左臂压住中线附近，右臂将衣物一侧向另一侧推折，或双臂分别抓住两个宽边做半折。折叠只要求衣物形成大致对折或明显压平堆叠，不要求衣角精准对齐。

折叠后，机器人把衣物推到干净暂存区。成功标准为衣物主体进入干净区并保持 1 秒。

## 数据采集设计

建议首轮采集 180-300 条 demonstrations：

- 待洗来源 90-150 条。
- 干净来源 90-150 条。
- 每类覆盖 3-5 种衣物初始摆放、轻微皱褶和抓取角度。
- 两类衣物都经过相同公共整理区和相同压平动作。
- 待洗分支覆盖海绵刷不同初始角度。
- 干净分支覆盖不同简单折叠方向，但不要让折叠方向与来源之外的变量绑定。

推荐分阶段采集：

- Stage A：只采待洗/干净各 30 条，验证取衣、放中间、刷/折动作可行。
- Stage B：扩展到 180 条，加入衣物初始姿态扰动。
- Stage C：加入 3/6/10 秒公共整理延迟，测试长记忆保持。
- Stage D：加入抽屉轻微平移、公共整理垫轻微平移，测试泛化。

## 成功标准

硬性成功条件：

- 机器人从指定抽屉侧成功取出衣物。
- 衣物被放入公共整理区。
- 待洗来源执行刷动并进入脏衣篓。
- 干净来源执行简单折叠并进入干净暂存区。
- 不使用人工中途提示或重置。

推荐量化指标：

- 来源分支选择准确率。
- 待洗分支刷动成功率。
- 脏衣篓投放成功率。
- 干净分支折叠成功率。
- 干净暂存区推送成功率。
- 完整任务成功率。
- 分支混淆率：待洗被折叠、干净被刷动。
- 延迟 sweep 下的分支选择准确率。

## 对照实验与消融

建议评估：

1. Full PRISM：path signature、delta signature、visual prefix memory、signature-indexed slot memory 全开。
2. Current Observation Only：关闭 PRISM 记忆，只使用当前观测。
3. Visual Prefix Memory Only：保留视觉前缀记忆，关闭 signature routing。
4. Signature Only：只使用 path/delta signature，不使用视觉前缀。
5. No-Delta Routing：保留 path signature，关闭 delta signature。
6. Source Distinct Upper Bound：故意让待洗/干净衣物外观差异明显，用于确认底层刷/折动作可学。

该实验最适合展示 current-observation baseline 在 Stage 3 分支处的失败，以及 PRISM 在长公共整理段后的保持能力。

## 防止捷径

需要避免：

- 待洗衣物和干净衣物使用明显不同颜色或纹理。
- 待洗衣物存在当前图像一眼可见的大污渍。
- 左侧和右侧取物后抽屉中剩余衣物数量差异过于明显。
- 待洗和干净在公共整理区落点不同。
- 示教者对两类任务使用不同节奏或停顿。
- 海绵刷位置、脏衣篓位置或干净区位置被提前朝向泄漏。

推荐诊断：

- Stage 3 current-frame probe：只用公共整理区当前图像预测待洗/干净，准确率应接近随机。
- Action-tail probe：只用公共整理阶段最后 1 秒状态预测来源，准确率应低于完整前缀。
- 分支混淆矩阵：检查错误是否主要发生在刷/折选择处。

## 训练配置建议

建议沿用 PRISM Diffusion 或 Streaming ACT 设置：

- `use_path_signature: true`
- `use_delta_signature: true`
- `use_visual_prefix_memory: true`
- `use_signature_indexed_slot_memory: true`
- `prefix_train_max_steps: 24` 或 `32`
- `prefix_frame_stride: 4` 到 `8`
- `slot_memory_num_slots: 4`
- `slot_memory_use_delta_routing: true`
- `slot_memory_use_readout_pooling: true`
- `slot_memory_balance_loss_coef: 0.05` 到 `0.1`
- `slot_memory_consistency_loss_coef: 0.001` 到 `0.005`

若使用 Diffusion Policy backbone，在线执行阶段建议减少 action queue：

- `n_action_steps: 1` 到 `5`

原因是刷/折分支需要及时响应 PRISM memory 读出的任务条件。

## 论文展示建议

该实验适合作为最直观的“日常双臂记忆分支任务”：

- 主表：完整成功率、分支选择准确率。
- 延迟图：公共整理延迟 0/3/6/10 秒下的成功率。
- 可视化：从抽屉来源写入，到公共整理保持，再到刷/折分支读出。

一句话叙事可以写为：机器人像整理抽屉衣物一样，把来自不同抽屉侧的相似衣物都先放到同一个公共区域，随后仍然记得它是待洗还是干净，从而选择刷洗丢篓或简单折叠。
