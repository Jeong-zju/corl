# PRISM 固定基座双臂实验三：序列处方记忆工具链

## 实验定位

推荐英文名：`Ordered Bimanual Tool-Chain Service`

推荐数据集名：`zeno-ai/OrderedBimanualToolChain`

该实验要求固定基座双臂机器人在任务开始时读取一张短暂可见的“工具处方卡”，然后按处方指定的顺序完成三步工具操作。处方卡随后被遮挡，机器人必须在多个工具之间按正确顺序选择、使用、归位。

该实验专门用于检验 PRISM 的多次写入、多次读出和顺序记忆能力。它比单次隐藏目标任务更难，因为机器人不仅要记住一个类别，还要记住一个有序序列，并在每一步完成后读取“下一步应该做什么”。

## PRISM 专属性

本实验的记忆需求与 PRISM 的 slot memory 高度匹配：

- 初始处方卡包含多个符号，适合写入不同 slot。
- 每个工具步骤之间有共享的夹持、归位、稳定工件动作，当前观测不能直接给出下一工具。
- delta signature 可以帮助区分“刚完成第几步”和“现在应该读出哪个记忆项”。
- attention readout 可以在不同阶段从 slot memory 中读取不同工具顺序。

如果只做“看见目标工具后立刻抓取”，普通视觉策略也能完成；本实验要求处方隐藏，并且每一步当前场景尽量相似，才能真正测试 PRISM。

## 固定基座双臂平台设置

机器人固定在一个工具台前。推荐使用现有三相机输入和 17 维零底盘格式：

- `observation.state`: `[0, 0, 0, left7, right7]`
- `action`: `[0, 0, 0, left7, right7]`

双臂角色建议：

- 左臂负责固定工件、打开工具托盘、按住夹具。
- 右臂负责主要工具抓取与操作。

也可以在部分 demonstrations 中交换左右臂角色，用于检验策略是否记住处方而不是固定手臂脚本。

## 场景布置

桌面中央放置一个工件座，周围放置 4 种工具。工具可以是真实工具，也可以是安全替代件：

- `T1`: 按压器，用于按下工件上的弹簧按钮。
- `T2`: 擦拭块，用于擦过工件表面指定区域。
- `T3`: 小拨杆，用于拨动工件侧边开关。
- `T4`: 旋钮钥匙，用于旋转工件顶部旋钮。

每条 episode 的处方从 4 种工具中选择 3 种，并指定顺序，例如：

- `T2 -> T4 -> T1`
- `T3 -> T1 -> T2`
- `T4 -> T2 -> T3`

处方卡只在开始阶段可见。工具本身始终可见，但工具可见不代表顺序可见。

## 任务流程

### Stage 1：读取处方卡

顶部小屏或纸卡显示三步工具序列，持续 2-3 秒后被遮挡。处方符号可以使用颜色、图标或简单字母，但训练和评估应保持一致。

为避免语言模型或字符识别成为主要难点，建议首轮使用四个清晰图标，而不是复杂文字。

### Stage 2：公共工件准备

左臂固定工件或打开工件夹具，右臂打开工具托盘。该阶段与处方无关，所有处方都执行相同准备动作。

### Stage 3：第一工具操作

机器人选择处方第一个工具，移动到工件对应操作区，完成一次操作，然后把工具放回统一归位区。

归位区建议固定，让当前视觉中的工具摆放尽量一致。不要让已用工具停在特殊位置，否则当前图像会泄漏步骤历史。

### Stage 4：第二工具操作

机器人读取记忆中的第二个工具，重复抓取、使用和归位。左臂继续稳定工件，必要时调整夹具。

### Stage 5：第三工具操作与结束

机器人读取第三个工具并完成操作。最后双臂回到结束姿态，工件保持在固定位置。

## 数据采集设计

建议首轮采集 240-480 条 demonstrations：

- 从 4P3 = 24 个可能序列中选择 12 个常用序列。
- 每个序列采集 20-40 条。
- 每种工具在第一、第二、第三位置都要出现。
- 工具初始位置做小范围扰动，但不改变工具身份。
- 每条 episode 都必须有处方遮挡后的公共准备动作。

推荐分阶段采集：

- Stage A：两步序列、三种工具，验证处方隐藏和工具操作。
- Stage B：三步序列、四种工具，固定左右臂角色。
- Stage C：加入部分左右臂角色交换。
- Stage D：加入延迟 sweep，在每步之间插入 3/6/10 秒工件稳定动作。

## 成功标准

硬性成功：

- 机器人开始时读取处方卡。
- 处方卡遮挡后不再出现。
- 三个工具按正确顺序被选择。
- 每个工具操作达到指定接触或位姿条件。
- 工具归位，工件没有掉落或明显移位。

推荐量化指标：

- Step-1 工具选择准确率。
- Step-2 工具选择准确率。
- Step-3 工具选择准确率。
- 完整顺序准确率。
- 工具操作成功率。
- 阶段进度：读卡、准备、第一工具、第二工具、第三工具。
- 顺序编辑距离：预测工具序列到真实处方序列的 Levenshtein 距离。

## 对照实验与消融

建议评估：

1. Full PRISM。
2. Current Observation Only。
3. Visual Prefix Memory without Signature Routing。
4. Signature Only。
5. No-Delta Routing。
6. Mean Readout：slot memory 使用平均读出，而不是 attention readout。
7. Card Always Visible Upper Bound：处方卡始终可见，用于确认基础工具操作可学。
8. Shuffled Prescription：评估时把处方视觉和执行目标错配，检查策略是否跟随处方。

该实验尤其适合检验 attention readout：如果 mean readout 表现下降，说明模型需要在不同阶段选择性读取不同 slot，而不是把全部历史压成一个平均向量。

## 防止捷径

需要控制下列泄漏：

- 已用工具不能留在特殊位置暴露顺序。
- 工件上每一步操作痕迹不能清晰提示下一步。
- 操作者不能因不同处方产生固定节奏差异。
- 工具托盘打开角度和夹具姿态不能与处方绑定。
- 处方卡遮挡后不能通过屏幕反光继续可见。

推荐诊断：

- Stage-2 当前图像处方分类 probe：准确率应接近随机序列水平。
- Stage-4 当前图像下一工具 probe：如果准确率过高，说明已完成步骤留下了视觉捷径。
- 使用工具序列混淆矩阵观察错误是否主要发生在第二、第三步。

## 训练配置建议

该任务需要更多 slot，因为处方是有序多项信息：

- `slot_memory_num_slots: 6` 或 `8`
- `prefix_train_max_steps: 32`
- `prefix_frame_stride: 4` 到 `6`
- `use_path_signature: true`
- `use_delta_signature: true`
- `use_visual_prefix_memory: true`
- `use_signature_indexed_slot_memory: true`
- `slot_memory_use_delta_routing: true`
- `slot_memory_use_readout_pooling: true`
- `slot_memory_balance_loss_coef: 0.05` 到 `0.1`
- `slot_memory_consistency_loss_coef: 0.005`

如果使用 PRISM-ACT，可以展示 decoder cross-attention 对处方卡帧和工具帧的关注变化；如果使用 PRISM-Diffusion，可以展示 PRISM conditioning 对不同工具动作 chunk 的影响。

## 论文展示建议

该实验适合展示：

- 三步工具选择准确率柱状图。
- 完整序列准确率随步骤间延迟变化的曲线。
- Full PRISM 与 Mean Readout 的对比，用于强调选择性 slot readout。
- 处方卡帧、第二步选择帧、第三步选择帧的 slot routing 可视化。

一句话叙事可以写为：机器人一开始读到一张工具处方，处方消失后，它要在多个相似的双臂操作阶段中按顺序记住下一步该拿哪一个工具。
