# LabelGuidedShelfDelivery

## 定位

这是一个面向移动操作与记忆能力展示的配送任务：机器人一开始看到不同的配送标签，然后从三层货架上取外观相同的标准货物，经过一段完全相同的运输路径，最后根据早期看到的标签把货物送到不同目的地。

推荐中文展示名：标签引导货架配送。

推荐数据集名：`zeno-ai/LabelGuidedShelfDelivery`。

任务基本概述是：看标签、取同款货物、走同一路径、按记忆投递。

## 核心流程

1. 机器人在起点看到一个配送标签。
   - 标签可以显示目的地，例如 `A 区`、`B 区`、`C 区`。
   - 标签只在任务开始阶段清晰可见，取货后会被遮挡或离开视野。

2. 机器人立刻去三层货架取货。
   - 三层货架分别是上层、中层、下层。
   - 三层货架上的货物外观完全相同，避免模型靠货物外观猜目的地。
   - 标签内容决定最终目的地，标签所在层或亮灯层决定从哪一层取同款货物。
   - 不同标签位置会触发不同取货轨迹，例如上层取货、中层取货、下层取货。

3. 机器人进入相同运输路径。
   - 取到货物后，机器人都要执行同一段动作：收货到托盘、后退、转身、穿过同一段走廊、到达同一个投递前区。
   - 这段路径在不同标签条件下尽量保持一致，用来测试记忆能否跨越相同动作序列。

4. 机器人根据标签记忆进入不同后续分支。
   - 到达投递前区后，当前视觉尽量相似，标签不再完整可见。
   - 机器人需要把货物送到标签指定的目的地，例如不同房间、不同投递柜、不同工作台。

5. 可扩展为多轮。
   - 完成一次投递后，机器人可以看到下一张标签，再重复取货、公共路径和投递流程。

## 任务关键点

这个任务的设计重点是让“早期标签 + 取货轨迹”成为后续投递分支的依据：

- 标签提供最终目的地信息。
- 三层货架让机器人产生不同的即时取货动作和轨迹。
- 货物外观相同，不能靠货物本身区分目的地。
- 中间运输路径相同，不能靠后半程当前视觉直接恢复答案。
- 最终目的地不同，必须保留并读取早期标签记忆。

因此，任务不是简单地识别标签后立刻分类，而是要在完成取货和长距离移动后，仍然保持标签对应的投递目标。

## 场地结构

场地由三个主要区域组成。

1. 标签与货架区
   - 一个三层货架，建议每层放一个外观相同的标准货物。
   - 每层高度要让取货动作明显不同：上层需要抬臂，中层接近自然高度，下层需要下探或蹲低式对齐。
   - 标签可以放在货架旁或起点电子牌上，要求机器人开始时能清晰看到。

2. 公共运输路径
   - 所有任务条件都经过同一段路径。
   - 推荐包括后退、转身、直行、绕过固定障碍、到达投递前区。
   - 这段路径要足够长，让记忆保持成为任务核心之一。

3. 投递区
   - 设置 3 个或更多目的地，例如 A/B/C 房间、A/B/C 柜格、A/B/C 工作台。
   - 投递区入口视觉尽量相似，避免机器人只靠当前画面直接选择。
   - 目的地可以在最后局部可见，用于末端对齐，但不应完整暴露早期标签答案。

## 标签设计

标签建议包含明确但不花哨的信息：

- 目的地：A/B/C 或 Room 1/2/3。
- 可选投递姿态：横放、竖放、标签朝外。
- 可选停靠偏移：靠左、居中、靠右。

首轮任务建议只让标签决定目的地，等流程稳定后再加入投递姿态或停靠偏移。

为了避免捷径，标签内容和货架层数不要永久绑定。例如同样是 `A 区` 标签，有时出现在上层，有时出现在中层；同样是上层取货，也可能对应不同目的地。这样模型必须同时记住视觉标签和取货过程，而不是学一个固定层数到目的地的映射。

## 数据采集设计

建议首轮采集 150-210 条 demonstrations：

- 3 个目的地，每个目的地 50-70 条。
- 3 个货架层，每层都覆盖所有目的地。
- 货物外观保持一致。
- 公共运输路径尽量一致。
- 标签只在开始和取货阶段可见，运输和投递阶段遮挡或不可见。
- 投递区入口视觉尽量相似。

推荐分阶段采集：

Stage A：标签决定 A/B/C 目的地，货物从固定中层取。

Stage B：加入三层货架取货，上/中/下层都放相同货物。

Stage C：标签和货架层解耦，所有目的地覆盖所有层数。

Stage D：加入双轮配送，一个 episode 内重复两次标签记忆与投递。

## 成功标准

硬性成功：

- 机器人正确读取初始标签。
- 机器人从三层货架取到外观相同的标准货物。
- 机器人经过规定的公共运输路径。
- 机器人将货物送到标签指定目的地。
- 标签在运输和投递阶段不再完整可见。
- 过程中没有人工提示、中途重置或直接暴露答案。

推荐量化指标：

- 目的地投递准确率。
- 三层货架取货成功率。
- 公共路径完成率。
- 投递前底盘停靠误差小于 15 cm。
- 隐藏标签条件下成功率显著高于无记忆或错配记忆条件。

## 对照实验

建议做四组评估：

1. 正式任务
   - 初始标签可见，取货后标签隐藏，机器人完成公共路径后投递。

2. 无标签记忆
   - 取货动作保留，但屏蔽初始标签或遮掉标签图像。
   - 机器人应该仍能取货和走公共路径，但投递目的地会明显下降。

3. 记忆错配
   - 初始标签和后续投递目标在评估时人为错配。
   - 如果模型确实使用标签记忆，投递会随错配发生系统性错误。

4. 标签始终可见
   - 包裹或屏幕上的标签在投递阶段一直可见。
   - 这是上限条件，用于确认机器人具备基础配送和放置能力。

## 和 CleanTableTopDelayedToolChoice 的区别

CleanTableTopDelayedToolChoice 更偏桌面任务，重点是早期条件影响后续工具或目标选择。

LabelGuidedShelfDelivery 的区别是：

- 任务是现实移动配送流程，不是桌面选择。
- 机器人需要从三层货架取同款货物，包含明显的移动底盘和手臂协同。
- 中间有一段相同运输路径，用来制造记忆保持需求。
- 最终目标是不同目的地投递，而不是选择不同物体。
- 可以扩展为多轮配送，重复测试记忆写入和读取。

## 训练配置建议

数据转换可以沿用当前 Zeno 17 维格式：

- `observation.state`: `[base_vx, base_vy, base_omega, left7, right7]`
- `action`: `[base_vx, base_vy, base_omega, left7, right7]`
- 图像 key: `observation.images.realsense_top/left/right`

建议保留记忆相关训练配置：

- `use_path_signature: true`
- `use_delta_signature: true`
- `use_prefix_sequence_training: true`
- `use_visual_prefix_memory: true`
- `use_signature_indexed_slot_memory: true`
- `slot_memory_use_delta_routing: true`

采集时要特别注意两点：三层取货动作要有足够轨迹差异，公共运输路径要尽量一致。前者提供可区分的动作历史，后者确保后续投递必须依赖早期标签记忆。

## 演示脚本

1. 镜头展示三层货架和初始配送标签。
2. 机器人看到 `A 区`、`B 区` 或 `C 区` 标签。
3. 机器人从三层货架取一个外观相同的标准货物。
4. 货物进入托盘后，标签不再可见。
5. 机器人沿同一条路径穿过走廊，到达投递前区。
6. 机器人根据记忆把货物送到正确目的地。
7. 更换标签重复一次：取货和公共路径类似，但最终目的地不同。

这套任务的叙事非常直接：机器人先看配送标签，取同款货物，走同一条路，最后仍然记得该送到哪里。
