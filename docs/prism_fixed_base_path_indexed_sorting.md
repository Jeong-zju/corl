# PRISM 固定基座双臂实验二：路径索引的隐式分拣装配

## 实验定位

推荐英文名：`Path-Indexed Bimanual Sorting`

推荐数据集名：`zeno-ai/PathIndexedBimanualSorting`

该实验不使用显式标签，而是让早期的取物来源和双臂接触路径成为隐式任务条件。机器人从四个对称来源槽中的一个取出外观完全相同的零件，经过统一中间整理动作后，需要把零件放入与来源槽唯一对应的目标装配槽。

该实验专门用于检验 PRISM 的 path signature 和 delta signature。正确答案不是由当前图像中的物体外观给出，而是由机器人已经执行过的轨迹前缀给出。

## PRISM 专属性

PRISM 的 signature-indexed slot memory 使用执行状态路径进行路由。本实验把任务条件设计为“身体走过的路径”，而不是显式视觉标签，因此非常适合检验 PRISM 是否真正利用 state-prefix signature。

核心难点如下：

- 四个来源槽的零件外观相同，抓起后无法通过零件本身判断来源。
- 取物区在中段被遮挡或重置，当前图像不能看到哪个来源槽被取空。
- 所有条件都经过同一个中间杯、同一个双臂交接动作和同一个目标前中立姿态。
- 最终四个目标装配槽外观相同，正确目标只能由早期取物路径恢复。

该实验与“看标签再行动”的任务互补：它更强调 PRISM 对机器人自身运动历史的编码能力。

## 固定基座双臂平台设置

机器人固定在桌前，不移动底盘。数据格式建议与当前仓库保持兼容：

- `observation.state`: `[0, 0, 0, left7, right7]`
- `action`: `[0, 0, 0, left7, right7]`
- 图像使用顶部相机和左右腕部相机。

如果之后希望做纯固定基座 14 维版本，也可以把前三个底盘维度去掉，但需要同步修改训练配置中的 `input_features` 和部署端 state/action 维度。首轮建议保留 17 维零底盘格式，减少工程变量。

## 场景布置

桌面左半区放置 2x2 来源槽，桌面右半区放置 2x2 目标槽。四个来源槽中每次只有一个槽是真正可取零件，或者四个槽都有零件但机器人被示教从指定槽取出一个。

来源槽建议命名为：

- Source A：左上
- Source B：右上
- Source C：左下
- Source D：右下

目标槽建议与来源槽做固定但不显式可见的映射：

- Source A -> Target C
- Source B -> Target A
- Source C -> Target D
- Source D -> Target B

映射不要使用直观空间对应关系，避免模型学习“从左上取就放左上”这类简单规则。

桌面中央放置一个中间杯或定位槽，所有零件都必须先放入中间杯，再由另一只手取出或双臂共同校正姿态。

## 任务流程

### Stage 1：来源槽取件

机器人从指定来源槽取出一个外观相同的小零件。零件可以是圆柱销、方形块、金属垫片或小夹具。

建议随机化：

- 使用左臂或右臂取件。
- 来源槽中零件初始旋转角。
- 来源槽周围微小遮挡。

来源槽本身不要有颜色或文字标签。任务条件来自机器人取件轨迹和早期视觉空间位置。

### Stage 2：来源区遮挡或重置

取件完成后，来源区被统一遮挡，例如滑盖关闭；或者四个来源槽都重新被相同遮挡板覆盖。

该设计非常重要：如果 Stage 4 当前图像还能看到哪个槽被取空，当前观测策略也能推断来源，实验就不再是 PRISM 专属。

### Stage 3：公共中间整理

机器人把零件放入桌面中央的中间杯。另一只手执行固定姿态校正，例如扶正零件、压入定位槽、转动 90 度、再取出。

所有来源条件都必须经过同一个中间整理动作。该阶段用来制造公共长前缀，让策略不能仅靠最后几帧动作判断来源。

### Stage 4：目标槽选择

机器人根据早期来源路径选择对应目标槽。四个目标槽外观完全一致，不显示编号。

双臂分工建议：

- 一只手持零件移动到目标槽上方。
- 另一只手扶住目标托盘或按住防滑边。

### Stage 5：装配或投放

机器人将零件插入目标槽、放入卡扣位或压入孔位。成功后双臂回到结束姿态。

## 数据采集设计

建议首轮采集 200-320 条 demonstrations：

- 4 个来源槽，每个 50-80 条。
- 左臂取件和右臂取件都覆盖。
- 目标映射固定，但空间上打乱。
- 每条都包含来源区遮挡和中间杯整理。

推荐分阶段采集：

- Stage A：两个来源槽、两个目标槽，验证遮挡机制和中间整理动作。
- Stage B：四个来源槽、四个目标槽，固定取件手。
- Stage C：随机取件手，要求 PRISM 记住来源而不是手别。
- Stage D：加入延迟和中间杯多步校正，拉长记忆窗口。

## 成功标准

硬性成功：

- 从指定来源槽成功取出零件。
- 来源区在最终选择前不可见或不可判别。
- 零件经过统一中间整理。
- 最终目标槽与来源槽映射一致。
- 零件稳定放入或装配到目标槽。

推荐量化指标：

- 来源条件识别准确率。
- 目标槽选择准确率。
- 完整装配成功率。
- 中间整理成功率。
- 错目标类型统计，例如是否偏向空间最近槽。
- 延迟 sweep 下的目标选择准确率。

## 对照实验与消融

建议评估：

1. Full PRISM。
2. Current Observation Only。
3. Signature Only。
4. Visual Prefix Memory Only：保留视觉前缀记忆但去掉 path/delta signature。
5. Prefix Memory without Signature Routing。
6. No-Delta Routing。
7. Source Visible Upper Bound：来源区不遮挡，用于确认基础抓放和目标槽动作可学。

该实验还适合做 signature depth 消融：

- depth 1：主要是一阶位移信息。
- depth 2：包含路径顺序的二阶信息。
- depth 3：与当前论文默认设置一致。

如果 depth 2/3 明显优于 depth 1，能更有力说明路径签名捕获了取件轨迹的顺序结构。

## 防止捷径

必须避免下列捷径：

- 来源槽被取空后仍暴露在相机视野中。
- 中间杯内零件姿态因来源不同而系统性不同。
- 取件手与来源槽固定绑定。
- 目标槽与来源槽空间位置一一对应。
- 操作者在不同来源条件下速度明显不同。

推荐做两个诊断：

- Current-frame source probe：只用 Stage 4 当前图像预测来源槽，准确率应接近 25%。
- Action-tail source probe：只用 Stage 3 最后 1 秒状态预测来源槽，准确率应明显低于完整前缀。

## 训练配置建议

本实验更依赖 path signature，建议优先使用：

- `use_path_signature: true`
- `use_delta_signature: true`
- `signature_depth: 3`
- `prefix_train_max_steps: 24` 或 `32`
- `prefix_frame_stride: 4` 到 `6`
- `slot_memory_num_slots: 4`
- `slot_memory_use_delta_routing: true`
- `slot_memory_balance_loss_coef: 0.1`
- `slot_memory_consistency_loss_coef: 0.005`

若 episode 较短，可以把 `prefix_frame_stride` 设小一点；若中间整理和延迟较长，可以增大到 8。

PRISM-Diffusion 在线评估时建议减少 action queue：

- 插放阶段：`n_action_steps: 1` 到 `5`
- 离线训练 horizon 可保持较长，以覆盖完整中间整理动作。

## 论文展示建议

该实验适合在论文中作为“轨迹条件记忆”证据：

- 表格展示四个来源槽的目标选择混淆矩阵。
- 折线展示 signature depth 与成功率关系。
- 可视化展示不同来源轨迹在 signature 空间或 slot routing 上形成不同写入模式。

一句话叙事可以写为：机器人拿到的是同一个零件，看不到任何标签，但它必须记住自己是从哪里、沿什么路径拿来的。
