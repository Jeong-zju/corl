# PRISM 固定基座双臂实验二：桌面线材整理

## 实验定位

推荐英文名：`Desktop Cable Organization`

推荐数据集名：`zeno-ai/DesktopCableOrganization`

该实验模拟日常桌面线材整理：桌面左侧放置三台设备或设备道具，右侧放置三根外观相同的线头。三根线的可见线头、颜色和粗拉环保持一致，但线的另一端分别连接到不同的功能来源，例如低电流充电器、快充电源和电脑数据同步口。机器人从右侧取出一根线头，将其放入桌面中心的横向导线槽，再沿导线槽牵引到左侧与该功能来源对应的设备区域。

标准版本中，一条 episode 可以依次整理三根线；为了降低首轮采集难度，也可以先做单根线版本：每条 episode 只从右侧三根线头中的一根开始，经过同一横向导线槽后放到对应设备的宽口线材区域。

该任务的核心是“相同线头的功能来源记忆”。三根线头外观一致，进入中心导线槽后当前画面主要看到相似线身、相似线头和同一条横槽。正确目标设备不是由线头外观决定，而是由这根线在右侧连接到哪个电源/数据源决定；机器人必须记住早期右侧线头来源位置、功能来源-设备映射，以及已经执行过的双臂路径。

重要限定：如果三根线在功能上完全可互换，例如都接到同一个普通充电器，那么该任务没有必要区分，不能作为 PRISM 记忆实验。该实验必须保证三根线有真实或任务语义上的非互换性，例如“低电流线应整理到小音箱”“快充线应整理到移动电源”“数据同步线应整理到手机/电脑同步设备”。

## PRISM 专属性

本实验专门检验 PRISM 在固定基座双臂线材任务中的长程记忆和路径条件能力。

- 早期视觉证据：机器人从右侧哪一个功能来源旁取出线头，以及左侧三台设备的自然外观。
- 共同中间状态：三根线都被放入同一个横向导线槽，线头外观一致，线身颜色和粗细保持一致。
- 双臂协作：一只手牵引线头，另一只手压住横槽中的线身，避免线材回弹或拖乱。
- 低精度目标：目标不是插孔对准，而是把线头放到设备旁的宽口线材区域或收纳槽中。
- 多次读出：如果标准 episode 连续整理三根线，PRISM 需要多次从 early source memory 中读出当前线头对应哪台设备。

普通 current-observation policy 在中心横槽阶段只能看到相同线头、相似线身和同一条公共导线槽，很难判断这根线来自慢充、快充还是数据同步来源。PRISM 的 visual prefix memory、path/delta signature 和 signature-indexed slot memory 应该能保留线头功能来源与目标设备的绑定关系。

## 固定基座双臂平台设置

机器人固定在桌前，不发布底盘动作。建议使用当前仓库兼容格式：

- `observation.state`: `[0, 0, 0, left7, right7]`
- `action`: `[0, 0, 0, left7, right7]`
- 图像输入：顶部相机、左腕相机、右腕相机。

双臂角色建议：

- 右臂负责从右侧线头槽夹住线头，并把线头牵引到横向导线槽入口。
- 左臂负责在横槽中压线、辅助导向，并在目标设备附近扶住设备或挡住线身回弹。
- 在目标放置阶段，右臂把线头放到设备旁的宽口线材区域，左臂轻压线身，避免线材回弹。

线头建议增加粗抓握段、软质夹持块或大号线扣，宽度 3-5 cm。设备旁的目标区域应是宽口托盘、浅槽或桌面标定区域，尺寸建议 8-15 cm，不要求插入端口。

## 场景布置

桌面左侧放置三台日常设备，不使用文字标签、屏幕提示或编号。设备可以是安全道具或闲置设备外壳：

- 低电流设备：例如小音箱、玩具相机或旧设备模型。
- 快充设备：例如移动电源、耳机盒模型或新设备模型。
- 数据同步设备：例如手机外壳、电脑旁同步底座或小平板模型。

每台设备旁放置一个宽口线材区域，用于接收对应线头。机器人不需要执行插头插入动作，只需要把线头整理到正确设备旁的有效区域。

设备布局应贴近日常桌面，不采用规则矩阵。推荐把三台设备放在左侧的前、中、后不同位置，形成浅弧形或自然错落关系。设备之间距离建议 15-25 cm，避免目标区域过近。

桌面中心设置横向导线槽：

- 长度建议 45-70 cm。
- 槽宽建议 5-8 cm。
- 槽内低摩擦，允许线材被牵引。
- 槽两端圆角，减少卡线。
- 三根线都必须经过同一段横槽，进入横槽后的视觉状态尽量一致。

桌面右侧放置三根外观相同的线头。三根线可以来自三个自然线槽、绕线器或充电底座边缘，但每根线的远端连接到不同功能来源。功能来源可以自然出现在桌面上，但不要用文字标签标出目标。

推荐右侧功能来源：

- 后方线头：连接到低电流充电器，适合小音箱或旧设备模型。
- 中央线头：连接到快充适配器或 PD 充电座，适合移动电源/耳机盒模型。
- 前方线头：连接到电脑 USB 口或数据同步底座，适合手机外壳/同步设备模型。

三根线的线头本体、颜色、形状和粗拉环都应一致。右侧每个来源区都保留相似的松散线圈或短线段，避免取走某根线头后当前画面直接显示“哪一路被拿走”。

建议固定但不显式展示的映射如下：

- 后方慢充线头 -> 低电流设备旁线材区域。
- 中央快充线头 -> 快充设备旁线材区域。
- 前方数据同步线头 -> 数据同步设备旁线材区域。

该映射只用于实验记录和示教，不向机器人提供任务 id。

## 任务流程

### Stage 1：右手从右侧线头槽取出线头

机器人从固定初始姿态开始，顶部相机能看到右侧三根线头、右侧功能来源、中心导线槽和左侧三台设备。右臂移动到指定功能来源旁的线头槽，夹住该线头的粗抓握段。

该阶段是记忆写入阶段。线头本身外观相同，主要来源信息来自右侧功能来源、线头槽的自然位置和机器人接近该线头时的路径。

### Stage 2：把线头放入横向导线槽

右臂把线头放入桌面中心横向导线槽。三根线都进入同一个横槽，并尽量在相似位置进入公共段。

左臂压住线身或扶住横槽边缘，让线材稳定进入槽内。该动作对三根线尽量一致，形成共享中间状态。

### Stage 3：沿导线槽牵引到左侧出口

右臂沿横槽牵引线头向左移动。左臂在槽中或槽边压线，避免线材弹出。三根线都经过同一段横向导线槽，当前画面中的线头和线身尽量不可区分。

该阶段是记忆延迟核心：机器人已经离开右侧来源位置，但还没有到达目标设备。

### Stage 4：根据来源选择目标设备区域

机器人根据早期线头功能来源，选择左侧对应设备区域：

- 后方慢充线头 -> 低电流设备旁线材区域。
- 中央快充线头 -> 快充设备旁线材区域。
- 前方数据同步线头 -> 数据同步设备旁线材区域。

右臂把线头牵引到目标设备旁的宽口线材区域。左臂可轻扶设备或压住线身，但不需要精确抓取设备。

### Stage 5：线头放置与线材整理

右臂把线头放入目标设备旁的宽口区域或浅槽内。左臂轻推线身，使线材在横槽中稳定，避免拉扯设备。

成功判定为线头主体落入正确设备旁的有效区域，并保持 1 秒。若线头被放到错误设备区域，记为目标选择错误；若目标选择正确但线头滑出区域，记为低层操作失败。

### 标准三线版本

在单根版本稳定后，可以扩展为一条 episode 连续整理三根线：

1. 取第一根线头，经横槽，放到对应设备区域。
2. 回到右侧，取第二根线头，经同一横槽，放到第二台设备区域。
3. 回到右侧，取第三根线头，经同一横槽，放到第三台设备区域。

三线版本更适合检验 PRISM 的多次写入、多次读出和阶段记忆，但控制和数据采集难度更高。建议作为第二阶段实验。

## 数据采集设计

建议分两个阶段采集。

单根线头版本建议首轮采集 210-360 条 demonstrations：

- 三个右侧功能来源各 70-120 条。
- 每类覆盖线材初始弯曲、线头朝向、横槽入口位置和目标设备轻微平移。
- 三类线都经过相同横槽公共段。
- 左臂压线动作尽量统一。
- 右臂靠近目标设备的最后放置动作允许自然变化。
- 右侧来源区在取线后仍保持相似线圈外观，防止当前图像直接暴露来源。

三线连续版本建议采集 180-300 条 demonstrations：

- 三根线整理顺序可固定为后方、中央、前方，首轮降低变量。
- 进阶版本可随机整理顺序，但必须保证最终三台设备都被正确整理到位。
- 每条 episode 包含三次右侧取线、三次横槽牵引和三次设备旁放置。
- 每个设备在第一、第二、第三次放置中都应出现。

推荐分阶段采集：

- Stage A：单根线，每类 20 条，验证线头抓取、横槽牵引和目标区域放置可行。
- Stage B：单根线扩展到 210 条，加入线材弯曲和设备轻微平移。
- Stage C：加入 3/6 秒横槽停顿或压线动作，拉长记忆窗口。
- Stage D：三线连续版本，先固定顺序，再加入顺序随机化。

## 成功标准

硬性成功条件：

- 右臂成功夹住指定线头。
- 线头被放入中心横向导线槽。
- 线材沿横槽被牵引到左侧设备区。
- 线头被放到与功能来源对应的设备旁区域。
- 线材没有严重缠绕、掉落或拉动设备离开区域。

推荐量化指标：

- 目标设备选择准确率。
- 功能来源记忆准确率。
- 横槽进入成功率。
- 横槽牵引成功率。
- 目标区域放置成功率。
- 完整单根任务成功率。
- 三线连续任务完整成功率。
- 错设备放置率。
- 目标选择正确但放置失败率。
- 延迟 sweep 下的目标选择准确率。

## 对照实验与消融

建议评估：

1. Full PRISM。
2. Current Observation Only。
3. Visual Prefix Memory Only。
4. Signature Only。
5. Prefix Memory without Signature Routing。
6. No-Delta Routing。
7. Source Visible Upper Bound：在目标选择阶段让右侧功能来源持续明显可区分，用于确认低层牵引和放置动作可学。
8. Single-Line Simplified：只放一根线，目标固定，用于测量线头牵引与目标区域放置的低层成功上限。

该实验适合展示 path signature 和 visual prefix memory 的互补性：右侧功能来源提供视觉上下文，取线和进入横槽的双臂路径提供状态前缀；两者在目标设备选择阶段共同发挥作用。

## 防止捷径

需要避免：

- 三根线使用不同颜色、长度或明显不同线头形状。
- 三根线进入横槽的位置明显不同。
- 右侧功能来源到左侧设备存在简单空间镜像关系。
- 目标设备按右侧线头顺序整齐排列。
- 线材长度差异导致拉动距离泄漏目标设备。
- 线头在横槽阶段仍露出可区分类别的线扣或标记。
- 当前图像能沿着线身直接追踪回右侧功能来源。导线槽应作为自然束线结构，让线材在公共槽内视觉上并行或部分重叠，而不是形成一眼可追踪的独立路径。
- 示教者在不同线头来源上使用固定节奏差异。

推荐诊断：

- Stage 3 current-frame probe：只用横槽牵引阶段当前图像预测目标设备，准确率应低于完整前缀。
- Action-prefix probe：比较只用右侧取线轨迹和只用目标前最后 1 秒轨迹的预测能力。
- Confusion matrix：观察错误是否偏向空间最近设备或固定设备。
- Mapping shuffle test：评估时改变右侧功能来源到设备的映射，检查策略是否真正依赖早期来源信息。

## 训练配置建议

本实验依赖右侧功能来源视觉、双臂路径和横槽公共段后的记忆读出，建议：

- `use_path_signature: true`
- `use_delta_signature: true`
- `signature_depth: 3`
- `use_visual_prefix_memory: true`
- `use_signature_indexed_slot_memory: true`
- `prefix_train_max_steps: 24` 或 `32`
- `prefix_frame_stride: 4` 到 `8`
- `slot_memory_num_slots: 4`，三线连续版本建议 `6`
- `slot_memory_use_delta_routing: true`
- `slot_memory_use_readout_pooling: true`
- `slot_memory_balance_loss_coef: 0.05` 到 `0.1`
- `slot_memory_consistency_loss_coef: 0.001` 到 `0.005`

若使用 PRISM-Diffusion，在线执行阶段建议减少 action queue：

- `n_action_steps: 1` 到 `5`

原因是目标区域放置阶段需要及时根据当前视觉误差修正末端位置。

## 论文展示建议

该实验适合展示：

- 三类功能来源到目标设备的混淆矩阵。
- 横槽公共段延迟增加时的目标选择准确率。
- 单根版本与三线连续版本的完整成功率。
- Full PRISM 与 Current Observation Only 的对比 rollout。
- slot routing 可视化：右侧功能来源写入、横槽牵引保持、左侧设备区域读出。

一句话叙事可以写为：机器人像整理桌面线材一样，从右侧取出三根外观相同、但分别连接慢充、快充和数据同步来源的线头，让它们都经过同一条横向导线槽，最后仍然记得每根线应该被整理到哪台设备旁。
