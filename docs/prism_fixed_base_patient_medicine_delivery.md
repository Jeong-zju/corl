# PRISM 固定基座双臂实验三：药品递送

## 实验定位

推荐英文名：`Patient Medicine Delivery`

推荐数据集名：`zeno-ai/PatientMedicineDelivery`

该实验模拟护理场景中的简化药品递送，但只使用安全道具，不使用真实药物。桌面左侧有三个托盘，分别代表三位不同患者。机器人从其中一个患者托盘取出相同外观的模拟药物，先放到桌面中间公共区域；随后从右侧取出与该患者对应的药盒，把模拟药物放入药盒中，再把药盒送回原来的患者托盘。

该任务的关键是“患者来源记忆”。药物本身完全相同，进入公共区域后无法从药物外观判断属于哪位患者；正确药盒选择和送回托盘都必须依赖早期患者托盘来源。

## 安全边界

该实验只用于机器人操作和记忆评估。实验中必须使用模拟药物，例如泡沫胶囊、塑料圆片或 3D 打印大号药片，不得使用真实药品，也不涉及真实患者用药决策。

药盒也建议使用空盒或道具盒。评价标准是物体放置是否正确，不评价医学有效性。

## PRISM 专属性

本实验高度适合 PRISM，因为它包含多次读写和长程来源绑定。

- 早期视觉证据：药物来自左侧哪个患者托盘。
- 中间公共状态：相同模拟药物被放到同一个中心小盘或软垫上，当前图像不包含患者身份。
- 第二阶段选择：机器人需要从右侧三个药盒中选择对应药盒。
- 第三阶段返回：装好药后，还要把药盒放回最初患者托盘。
- 记忆要求不止一次：先读出“取哪个盒子”，再读出“送回哪个托盘”。

普通 current-observation policy 在药物进入公共区域后只能看到相同药物和三个药盒，缺少患者来源信息。PRISM 的 visual prefix memory 和 signature-indexed slot memory 应该能保留患者托盘来源，并在后续两次决策中读出。

## 固定基座双臂平台设置

机器人固定在桌前，不移动底盘。建议使用当前仓库兼容格式：

- `observation.state`: `[0, 0, 0, left7, right7]`
- `action`: `[0, 0, 0, left7, right7]`
- 图像输入：顶部相机、左腕相机、右腕相机。

双臂角色建议：

- 左臂负责从患者托盘取模拟药物，并在最终阶段辅助定位托盘。
- 右臂负责从右侧取药盒、打开或扶住药盒、把药盒送回。
- 两臂共同完成“药物放入盒子”的宽口投放动作。

为了避免精细操作：

- 模拟药物尺寸建议 3-5 cm，可做成大号胶囊或圆片。
- 药盒使用开口盒、翻盖已打开的盒或宽口收纳盒，不做小孔投放。
- 患者托盘尺寸建议 18-25 cm，允许区域级放回。

## 场景布置

桌面左侧放置三个患者托盘，不使用文字姓名、电子屏幕或显式编号。可以用自然日用品区分患者场景，但不要让它们成为太直白的任务牌：

- 患者托盘 A：旁边有水杯和餐巾。
- 患者托盘 B：旁边有眼镜盒和纸巾。
- 患者托盘 C：旁边有小毛巾和杯垫。

三个托盘采用自然错落布局，例如沿左侧形成浅弧形或前中后分布，不摆成规则矩阵。

每个托盘中放 1-2 个相同外观的模拟药物或同色占位片。每条 episode 只从其中一个托盘取出一枚模拟药物。取走后托盘仍保留相似占位片，不出现明显空位。

桌面中间放置公共药物暂存区：

- 一个浅碟、软垫或小托盘。
- 所有患者来源的药物都先放到这里。
- 药物在这里的姿态尽量统一。

桌面右侧放置三个不同药盒：

- 药盒 1：宽口蓝色盒。
- 药盒 2：宽口白色盒。
- 药盒 3：宽口透明盒。

药盒可以外观不同，因为任务不是识别盒子，而是记住哪位患者对应哪个盒子。患者托盘到药盒的映射由实验记录固定，但不使用文字标识。例如：

- 托盘 A -> 蓝色盒。
- 托盘 B -> 白色盒。
- 托盘 C -> 透明盒。

右侧药盒不要按左侧托盘的空间顺序镜像摆放，避免简单最近邻规则。

## 任务流程

### Stage 1：从患者托盘取模拟药物

机器人从初始姿态开始，观察左侧三个患者托盘和中间公共区。机器人从指定患者托盘中取出一枚模拟药物。

该阶段写入患者来源信息。托盘旁的自然日用品只用于让场景像真实护理桌，不使用文字姓名或明显编号。

### Stage 2：放到中间公共区

机器人把模拟药物放到中间公共药物暂存区。三位患者的药物都经过同一位置、同一放置动作和同一短暂停顿。

此时当前画面只包含相同药物和相似患者托盘，不能可靠判断药物来自谁。

### Stage 3：从右侧取对应药盒

机器人根据早期患者托盘来源，从右侧三个药盒中选择对应药盒。右臂抓取药盒的宽边或粗把手，移动到中间公共区附近。

药盒抓取面要宽，允许粗略夹持。药盒可以预先打开，避免小铰链和精细开盖动作。

### Stage 4：将模拟药物放入药盒

机器人把中间公共区的模拟药物放入药盒。可以采用两种低精度方式：

- 左臂拿药，右臂扶住宽口药盒。
- 右臂拿盒靠近药物，左臂把药推入盒内。

成功标准为模拟药物进入药盒内部有效区域，不要求盒盖闭合。

### Stage 5：药盒送回原患者托盘

机器人把装有模拟药物的药盒放回最初取药的患者托盘。这个阶段再次需要读出患者来源，而不是只记住刚选择了哪个盒子。

成功标准为药盒主体落入原患者托盘有效区域，并保持 1 秒。

## 数据采集设计

建议首轮采集 270-450 条 demonstrations：

- 三个患者托盘各 90-150 条。
- 每个患者覆盖不同模拟药物初始位置、托盘轻微平移和药盒初始角度。
- 每条 episode 都包含中间公共暂存区。
- 每个药盒都在右侧不同自然位置出现，位置轻微扰动但不改变身份。
- 取药、放中间、取盒、装盒、送回五个阶段都完整采集。

推荐分阶段采集：

- Stage A：每个患者 20 条，验证取药、装盒、送回动作。
- Stage B：扩展到 270 条，固定药盒位置和托盘位置。
- Stage C：加入托盘和药盒轻微扰动。
- Stage D：加入 3/6/10 秒公共区等待或手臂归中动作，测试长延迟来源记忆。

## 成功标准

硬性成功条件：

- 从指定患者托盘成功取出模拟药物。
- 模拟药物进入中间公共区。
- 选择与患者对应的药盒。
- 模拟药物进入药盒。
- 药盒被送回原患者托盘。
- 全程不使用真实药物和真实患者信息。

推荐量化指标：

- 患者来源记忆准确率。
- 药盒选择准确率。
- 装盒成功率。
- 原托盘返回准确率。
- 完整任务成功率。
- 错误类型统计：选错盒、装盒失败、送回错托盘。
- 延迟 sweep 下的药盒选择和托盘返回准确率。

## 对照实验与消融

建议评估：

1. Full PRISM。
2. Current Observation Only。
3. Visual Prefix Memory Only。
4. Signature Only。
5. Prefix Memory without Signature Routing。
6. No-Delta Routing。
7. Single-Read Ablation：只在药盒选择阶段读 memory，送回阶段不再读 memory，检验多次读出价值。
8. Patient Visible Upper Bound：让患者托盘中留下明显来源差异，用于确认装盒和送回动作可学。

该实验尤其适合展示 PRISM 的多次读出能力：同一条 early source memory 需要支持“选盒”和“送回原托盘”两个相隔较远的决策。

## 防止捷径

需要避免：

- 三个患者托盘使用明显文字标签或编号。
- 取药后某个托盘出现明显空位。
- 药盒按患者托盘空间顺序镜像摆放。
- 不同患者的模拟药物颜色、形状或大小不同。
- 示教者对不同患者使用不同节奏或手势。
- 药盒选择后，机器人只靠药盒颜色推断送回位置；送回仍应依赖患者来源映射。

推荐诊断：

- Stage 2 current-frame probe：只用药物在中间公共区的当前图像预测患者来源，准确率应接近随机。
- Stage 4 current-frame probe：只用装盒前当前图像预测原患者托盘，准确率应低于完整前缀。
- Box-to-tray shortcut probe：打乱药盒到患者托盘映射，检查策略是否真正跟随早期患者来源。

## 训练配置建议

该任务包含两次记忆读出，建议 slot 数略大于二分类任务：

- `use_path_signature: true`
- `use_delta_signature: true`
- `signature_depth: 3`
- `use_visual_prefix_memory: true`
- `use_signature_indexed_slot_memory: true`
- `prefix_train_max_steps: 32`
- `prefix_frame_stride: 4` 到 `8`
- `slot_memory_num_slots: 6`
- `slot_memory_use_delta_routing: true`
- `slot_memory_use_readout_pooling: true`
- `slot_memory_balance_loss_coef: 0.05` 到 `0.1`
- `slot_memory_consistency_loss_coef: 0.001` 到 `0.005`

若使用 PRISM-Diffusion，建议在线执行阶段将 action queue 设短：

- `n_action_steps: 1` 到 `5`

这样药盒选择和送回阶段可以及时响应 memory readout。

## 论文展示建议

该实验适合展示：

- 三患者条件下完整成功率。
- 药盒选择准确率与送回托盘准确率分开报告。
- Full PRISM 与 Single-Read Ablation 的对比。
- slot routing 可视化：患者来源写入、中间公共区保持、选盒读出、送回托盘再次读出。

一句话叙事可以写为：机器人像护理桌上的药品递送一样，从某位患者托盘取出相同药物，放到公共区后仍记得它属于谁，随后选择对应药盒并把装好的盒子送回原患者托盘。
